# God Tier Prompts

One-sentence prompts for coding agents where every word does work ([what qualifies](CONTRIBUTING.md#what-makes-a-prompt-god-tier)). A prompt gets in only when at least 3 people ran it on their own code and posted a public receipt (a PR, an issue, or a screenshot of what it found). Fewer than five prompts is fine. The list stays small on purpose.

| # | Prompt | Receipts |
|---|---|---|
| 01 | [`find all of the implicit state machines in my app`](prompts/01-implicit-state-machines.md) | Adobe, Foundry, Alloy, Hyperlane and more ([list](prompts/01-implicit-state-machines.md#who-vouched-for-it)) |

## Use one

Open Claude Code, Codex or Cursor in your repo, paste the prompt, and read the report before you let the agent change code.

## Add one

Open a [Suggest a prompt](../../issues/new?template=new-prompt.yml) issue. It waits as a candidate until 3 people comment with receipts. Open candidates: [issues](../../issues?q=is%3Aissue+is%3Aopen+label%3Acandidate) and [PRs](../../pulls?q=is%3Apr+is%3Aopen+label%3Acandidate). Give a 👍 to the ones you want in. Rules: [CONTRIBUTING.md](CONTRIBUTING.md).
