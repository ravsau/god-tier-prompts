# Candidates

These prompts came up in the replies to prompt 01. They look useful, but nobody has posted results from them yet, so they are not in the collection. A candidate moves to `prompts/` when two or three people run it and show what it found (see [AGENTS.md](AGENTS.md)).

If you run one of these, open a "Vouch for a prompt" issue with a link to your results. To add a new candidate, open a "Suggest a prompt" issue.

## The smallest abstraction that removes a class of problems

```
Find the recurring problems, duplicated logic and hidden complexity across my codebase. Then identify the smallest, most powerful higher-level abstraction that would make entire classes of these problems disappear by design, not just hide them behind another layer.
```

Posted by [pooomj (@Dyikhyi56)](https://x.com/Dyikhyi56).

## Point and call

Make the agent say out loud everything it changed, the way train drivers point at each signal and call it. From a list of frameworks that [Minh Nhat Nguyen (@menhguin)](https://x.com/menhguin) gives agents: Chesterton's fence with design docs, point-and-calling, commander's intent with OODA loops, and autonomy levels L1 to L5. Needs to become one sentence before it can move up.

## Empirical plus formal verification

```
use empirical verification combined with formal verification to review
```

For code reviews. The author is still testing it.
